# Operations Analytics - Week 4, Session 3: Combining Decision Trees, Simulation, and Optimization

This session introduces a more advanced decision-making approach by combining **decision trees, simulation, and optimization**. In previous sessions, simulation was used to evaluate complex uncertain outcomes. In this session, optimization is added to handle situations where a decision maker has many possible choices instead of only a few alternatives. The example continues with IDEA's Krusbar tent supplier selection problem.

The demand model remains the same:

* 50% probability of a **Weak Market**
* 50% probability of a **Strong Market**

Demand is modeled using Uniform Distributions:

* Weak Market: Demand between 2,000 and 8,000 units
* Strong Market: Demand between 6,000 and 14,000 units

Every value within these ranges is equally likely.

Previously, Supplier P required IDEA to order a fixed quantity of 10,000 units. Under a new contract, Supplier P offers more flexibility:

* Fixed upfront charge increases from €50,000 to €100,000.
* Initial order must be at least 4,000 units.
* Additional units can be ordered later after market conditions become known.
* Total order quantity (Q) can range from 4,000 to 10,000 units.

This flexibility allows IDEA to adjust inventory according to market conditions, potentially increasing profitability.

### Profit Model

Let:

* (Q) = Order Quantity
* (D) = Demand

Sales equal the smaller of demand and inventory:

[
Sales = \min(D,Q)
]

Revenue:

[
150 \times \min(D,Q)
]

Supplier P Costs:

[
100,000 + 100Q
]

Profit:

[
Profit = -100,000 - 100Q + 150 \times \min(D,Q)
]

Unlike earlier sessions, (Q) is no longer fixed and becomes a decision variable that can be optimized.

### Simulation and Optimization Process

Instead of evaluating every possible order quantity manually, IDEA uses the following process:

1. Generate many demand samples using simulation.
2. Calculate profit for each sample.
3. Compute average profit across all samples.
4. Use Excel Solver to choose the order quantity (Q) that maximizes average profit.

Constraints:

[
4000 \leq Q \leq 10000
]

The objective is to maximize average profit. Because the profit formula contains the MIN function, the model is nonlinear, so Solver uses the **GRG Nonlinear** method.

### Weak Market Optimization Results

Using only 10 simulated demand samples:

* Optimal Order Quantity ≈ 4,000 units
* Average Profit ≈ €18,150

However, 10 samples provide unstable estimates.

Using 1,000 simulated demand samples:

* Optimal Order Quantity ≈ 4,138 units
* Average Profit ≈ €51,646

This demonstrates that larger simulations produce more reliable optimization results.

### Strong Market Optimization Results

Using 1,000 simulation runs:

* Optimal Order Quantity ≈ 8,850 units
* Average Profit ≈ €268,862

Since demand is generally higher in a strong market, the optimal order quantity is much larger than in the weak market scenario.

### Updating the Decision Tree

The optimized simulation results are inserted into the decision tree.

#### Supplier S

Weak Market Profit:

[
42,405
]

Strong Market Profit:

[
150,000
]

Expected Value:

[
0.5(42,405)+0.5(150,000)
=96,202
]

#### Supplier P

Weak Market Profit:

[
51,646
]

Strong Market Profit:

[
268,862
]

Expected Value:

[
0.5(51,646)+0.5(268,862)
=160,254
]

No Supplier:

[
0
]

Expected Value = 0.

### Best Decision

Comparing expected values:

| Option      | Expected Value (€) |
| ----------- | ------------------ |
| No Supplier | 0                  |
| Supplier S  | 96,202             |
| Supplier P  | 160,254            |

The optimal decision is **Supplier P**.

In the previous session, Supplier P generated an expected profit of only about €6,575 because IDEA was forced to order 10,000 units regardless of market conditions. The new contract allows flexible ordering, increasing expected profit to approximately **€160,254**. This flexibility creates substantial value and completely changes the preferred supplier.

### Key Takeaways

Decision trees help structure decisions under uncertainty, simulation evaluates complex uncertain outcomes, and optimization identifies the best decision among many alternatives. By combining all three techniques, businesses can solve realistic decision-making problems involving uncertainty, inventory planning, supplier selection, and order quantity decisions. This approach is essentially a practical solution to the classic **Newsvendor Problem**, where companies must determine the inventory level that maximizes expected profit under uncertain demand.
